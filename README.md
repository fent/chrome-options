# chrome-options demo

An example Chrome extension demonstrating [chrome-options](https://github.com/fent/chrome-options).

View the live demo at [fent.github.io/chrome-options](https://fent.github.io/chrome-options/).

## Running as an Unpacked Extension

1. Clone or download this branch.
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select this directory.
5. Click **Details** -> **Extension options** to open the options page.
